Agent-oriented programming (AOP) is a programming paradigm where the construction of the software is centered on the concept of software agents. Multi-Agent Reinforcement Learning (MARL) is a sub-field of reinforcement learning that focuses on the behavior of multiple learning agents coexisting in a shared environment. Agent-oriented systems are computational frameworks in which autonomous entities—agents—interact, cooperate, and coordinate to achieve individual or collective goals in complex, distributed environments.
